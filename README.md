# PhiloMind — image-led multi-page version

This version restores the original PhiloMind home page look: a large scenic hero image, the quote on the right, image-backed reflection/community panels, and the featured-philosopher portraits. The top navigation and main feature cards link to separate HTML pages.

## Files
- `index.html` — home page, retaining the original image-led design
- `philosophers.html` — philosopher directory
- `ideas.html` — philosophical ideas and traditions
- `branches.html` — branches of philosophy
- `personality-test.html` — exploratory philosophical profile quiz
- `thought-lab.html` — thought experiments
- `writing.html` — philosophy writing studio
- `reflection.html` — reflection journal
- `timeline.html` — philosophy timeline
- `assets/` — shared CSS, content data, and JavaScript for the dedicated pages

## Publish to GitHub Pages
Upload the contents of this folder to the repository root. Do not upload only the ZIP or place the contents inside an extra nested folder. Replace the existing `index.html` with this version, add the other HTML files, and upload the `assets` folder. Keep all files on the same branch and in the same root folder used by GitHub Pages.

The home page uses remote Unsplash image URLs and Google Fonts, so those visuals require an internet connection.
